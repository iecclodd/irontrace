# Shared implementation contracts

All Python imports use `nextcheck` under backend. Working directory is repository root. Artifact root defaults to repo/artifacts; env NEXTCHECK_ARTIFACTS overrides. Seed 20261004. Public manifest lives at root/demo_manifest.json. Panels ordered `initial`, `pressure`, `flow`, `vibration`, `power`, `temperature`; initial is TS1. Feature order follows panels, sensors, statistics `mean,std,min,max,slope`. labels 0,1,2.

## Data/model (data worker owns manifest and pyproject)
`nextcheck.data.extract.prepare(raw_dir, output_dir) -> dict` saves features.npz keys X (n,70), y (n,), cycle_ids and feature_names, metadata.json. `nextcheck.data.split.make_splits(y, seed=20261004) -> dict` containing context,utility,selection,test,unused row-index lists, block_ids and metadata. Save splits.json. `nextcheck.model.tabpfn35.TabPFN35Predictor(context_X, context_y, **kwargs)` fits once, `predict_proba(X)->array[n,3]`, `provenance` dict. Raises explicit ModelUnavailable; no fallback. Provenance readiness only after predict succeeds. `scripts/prepare_data.py` and doctor runnable from root. Shared prepared artifacts: artifacts/data/features.npz, splits.json, metadata.json; model doctor artifacts/model_status.json.

## Numerics
`nextcheck.acquisition.scores.diagnostics(q0, qm)->dict` raw_kl,information,residual,entropy_drop.
`nextcheck.acquisition.sampler.DonorSampler(context_X, panels)` where panels is list manifest panels with id,features (column indexes OR resolve schema; settle via message), `sample(observed, candidate_id, seed, draws=16)->(rows, diagnostics)` returns hypothetical complete-width NaN-masked rows.
`nextcheck.agent.state.ObservedCase` contains only visible group IDs and visible feature values, no case/row IDs or labels. Prefer dataclass with `observed_groups: tuple[str,...]`, `values: dict[str,float]`. Numeric engine `nextcheck.agent.loop.AcquisitionEngine(predictor, context_X, manifest, utility_model=None)` exposes `analyze(observed, remaining_budget, policy='information', lambda_cost=.02, seed=20261004)->dict`, with probabilities, candidates, selected_action, stop_reason, inference_ms, state_hash. Candidate dict keys group_id,cost,affordable,raw_kl,information,residual,entropy_drop,predicted_delta,net_value,sampler. Policies prior,initial,static,random,raw_kl,information,entropy_drop,value,value_no_residual,all. Numerics supports diagnostic policies and value; evaluation handles prior/static/random etc when sensible. Hidden replay owned separately: `ReplayEnvironment` holding row and label, charged reveal after validated chosen action. Policy never receives it.

## Value/evaluation
`nextcheck.acquisition.utility` is EVALUATION worker owned. `UtilityModel` with `.predict(candidate, observed_groups, probabilities)->float`, `.save(path)`, `.load(path)`. Diagnostics features: information,residual,entropy,margin,observed mask,candidate one-hot, observed-only donor stats. Ridge fit only utility; select alpha on selection. Engine will call predict with those arguments. Evaluation CLI must persist execution_status with blockers if model unavailable, never fabricate. Frozen selection before test predictions. Benchmark manifests list summaries under artifacts/run_*/summary.json, status and per-case JSON. Coordinator adapts benchmark API to this format.

## API/UI
GET health: {status:'ready'|'blocked'|'loading',model_ready:bool,data_ready:bool,blockers:string[],mode:'live',utility_ready:bool}. GET model-info provenance. GET demo-manifest panels {id,name,sensors,cost,features:string[]}, labels:string[].
POST sessions {budget:number=6,lambda_cost:number=.02,policy:string='information',costs?:Record<string,number>} -> session. Session shape: {id,version,status:'active'|'completed'|'error',mode:'live',budget,spent,remaining_budget,policy,lambda_cost,observed_groups:string[],visible_values:Record<string,number>,probabilities:number[]|null,recommendation:Analysis|null,trace:Event[],stop_reason:string|null,inference_ms:number,model_ref:string}. No label until separate completed report.
Mutation bodies {version:number}; recommend -> {job_id}; run -> {job_id}; acquire adds {group_id,idempotency_key} -> session; stop -> session. GET jobs/id {id,status:'queued'|'running'|'completed'|'error',progress:number,error:string|null,result:unknown}. recommend requires async poll then GET session. All jobs serialized. Analysis as above. Candidate order ranked. GET trace -> {events:Event[]}; event {kind,timestamp,...sanitized fields}. GET report completed only -> {session, true_label,log_loss,...}. GET benchmarks -> {runs:[],blockers:[]}. GET replays -> {replays:[]}; GET replays/{id} returns immutable actual recorded trace or 404. Fixtures never exposed by production server. UI unavailable empty state supports all screens while access blocked. Export active trace sanitized.
